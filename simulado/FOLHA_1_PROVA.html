QUESTÃO 1 (1,0 pt) — LISTA PRÓPRIA (:>:)
ENUNCIADO: Dado List a = a :>: (List a) | Nulo, implemente removerElementoInicio. 
data List a = a :>: (List a) | Nulo deriving (Show, Eq)

-- Resposta oficial (remover primeiro):
removerElementoInicio :: List a -> List a
removerElementoInicio (x :>: xs) = xs
removerElementoInicio Nulo       = Nulo

-- 🚨 DICA DO PROFESSOR: REMOVER DO MEIO (por valor):
removerMeio :: (Eq a) => a -> List a -> List a
removerMeio _ Nulo = Nulo
removerMeio val (x :>: xs)
  | val == x  = xs                      -- achou: descarta x
  | otherwise = x :>: removerMeio val xs -- mantém e segue

-- 🚨 REMOVER POR POSIÇÃO (índice 0, 1...):
removerPos :: Int -> List a -> List a
removerPos _ Nulo = Nulo
removerPos 0 (_ :>: xs) = xs
removerPos n (x :>: xs) = x :>: removerPos (n-1) xs

SUAS ANOTAÇÕES: DATA, TYPE E ESTRUTURAS RECURSIVAS (SUAS PALAVRAS)
• data (Caixinhas com Etiquetas): Inventa um tipo novo que não existia no Haskell. O pipe | é simplesmente um OU (uma caixinha com etiqueta Casa OU Apartamento). Os construtores SEMPRE começam com letra MAIÚSCULA!
• type (Apelido): Não cria tipo novo, só dá apelido pra tuplas ou listas que já existem: type Nome = String | type Ponto = (Float, Float) | type Coord = (Int, Int)
• Estruturas Recursivas (Boneca Russa): caixinha dentro de caixinha. :>: é o cons (junta cabeça com cauda) e Nulo é a lista vazia []. Para remover o primeiro elemento, pegamos a cauda xs e jogamos fora a cabeça x!

QUESTÃO 5 (1,0 pt) — AVALIAÇÕES RÁPIDAS & TIPOS
(a) :t filter odd       ==> Integral a => [a] -> [a]
(b) map (\\x->x*2) [1,3,5,7] ==> [2, 6, 10, 14]
(c) :t ("abc", True)    ==> ([Char], Bool)
(d) foldl (+) 0 [2,4,6,8] ==> 20
(e) [x*3 | x<-[1..6], x>3] ==> [12, 15, 18]
ANALOGIAS: A LINHA DE FÁBRICA
• map (Transformador): aplica a ferramenta em cada item:
  map (\\x -> x*2) [1, 3] => [2, 6] (mesmo tamanho)
• filter (Porteiro): só deixa passar quem der True:
  filter odd [1, 2, 3, 4] => [1, 3]
• foldl (Triturador): acumula em um único valor:
  foldl (-) 10 [1, 2, 3] => ((10-1)-2)-3 = 4 (esq->dir)
