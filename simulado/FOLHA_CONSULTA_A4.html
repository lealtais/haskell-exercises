1. DEFINIÇÃO DE NOVOS TIPOS COM DATA (Tipos Algébricos)

data NomeDoTipo = Construtor1 TipoA TipoB | Construtor2 TipoC deriving (Show, Eq) 

-- O símbolo | significa "OU". Construtores sempre começam com letra MAIÚSCULA!
-- Modelo 1: Casa e Apartamento com metragem (Float) e preço (Float)
data Imovel = Casa Float Float
            | Apartamento Float Float
            deriving (Show, Eq)

-- Modelo 2: Bairro com lista de imóveis [Imovel], descrição (String) e preço médio (Float)
data Bairro = Pompeia [Imovel] String Float
            | SantaMaria [Imovel] String Float
            deriving (Show, Eq)

-- Alternativa válida: Record Syntax (com nomes de campos explícitos)
data Produto = Produto { nome :: String, preco :: Float, estoque :: Int } deriving Show
2. LISTA PRÓPRIA (Operador :>: e Nulo)

Substitui : por :>: e [] por Nulo. 

data List a = a :>: (List a) | Nulo 
            deriving (Show, Eq)

-- Remover o primeiro elemento (head) e retornar a cauda:
removerElementoInicio :: List a -> List a
removerElementoInicio (x :>: xs) = xs
removerElementoInicio Nulo       = Nulo

-- Pegar a cabeça:
cabeca (x :>: _) = x

-- Inserir no início:
inserirInicio x lista = x :>: lista
3. ÁRVORES BINÁRIAS (Galho, Folha, Nulo)

Estrutura com bifurcação: Galho VALOR ESQ DIR 

data Arvore a = Galho a (Arvore a) (Arvore a)
              | Folha a
              | Nulo 
              deriving (Show, Eq)

-- Como instanciar árvore da imagem no papel:
-- Raiz 30; Esq: Galho 20 (Nulo, Folha 3); Dir: Galho 45 (Folha 41, Nulo)
arvoreExemplo :: Arvore Int
arvoreExemplo = 
  Galho 30 (Galho 20 Nulo (Folha 3))
           (Galho 45 (Folha 41) Nulo)
4. DIFERENÇA VITAL: TYPE vs DATA
• type (Sinônimo / Apelido): NÃO cria tipo novo. Só dá um apelido para tipos que já existem.
  type Nome = String
  type Ponto = (Float, Float)        -- apelido para uma tupla existente
  type Coord = (Int, Int)

• data (Novo Tipo Algébrico): CRIA um tipo que não existia no Haskell. Exige Construtores com MAIÚSCULA.
  data Dir = Norte | Sul | Leste | Oeste deriving Show
  data Booleano = Falso | Verdadeiro
Regra de Ouro da Frente: Na prova, todo construtor de tipo começa com Letra Maiúscula (ex: Galho, Folha, Casa, Pompeia). Parênteses são obrigatórios em sub-árvores!

5. A FUNÇÃO BAR (FILTER DISFARÇADO) E TESTE DE MESA PASSO A PASSO
bar :: (Eq a) => (a -> Bool) -> [a] -> [a]
bar func [] = []
bar func (x:xs)
  | func x == True = x : bar func xs     -- se func deu True, mantém o elemento x
  | otherwise      = bar func xs         -- caso contrário, descarta o elemento x

O que essa função faz? Filtra a lista, retornando apenas elementos que satisfazem o predicado (é a função 'filter').

Teste de Mesa Exigido: bar (\x -> elem x "FEfe") "FATEC"

Chamada Elemento x Cauda xs Condição elem x "FEfe" Ação / Retorno
bar func "FATEC" 'F' "ATEC" True ('F' está em "FEfe") 'F' : bar func "ATEC" (Mantém 'F')
bar func "ATEC" 'A' "TEC" False ('A' não está) bar func "TEC" (Descarta 'A')
bar func "TEC" 'T' "EC" False ('T' não está) bar func "EC" (Descarta 'T')
bar func "EC" 'E' "C" True ('E' está em "FEfe") 'E' : bar func "C" (Mantém 'E')
bar func "C" 'C' "" (vazia) False ('C' não está) bar func "" (Descarta 'C')
bar func "" - - Caso base (lista vazia) []

Resultado final reconstruído: 'F' : ('E' : []) = ['F', 'E'] = "FE"

6. ALTA ORDEM (MAP, FILTER, FOLDL)
• map (\x -> x * 2) [1,3,5,7]
  => Aplica em cada item: [2, 6, 10, 14]

• filter odd [1, 2, 3, 4]
  => Mantém apenas ímpares: [1, 3]

• foldl (+) 0 [2,4,6,8]
  => Acumula da esquerda para direita:
     (((0 + 2) + 4) + 6) + 8 = 20

• foldl (-) 10 [1, 2, 3]
  => ((10 - 1) - 2) - 3 = 4
7. LIST COMPREHENSION E TIPOS (:t)
• [x * 3 | x <- [1..6], x > 3]
  1. Gerador 1..6: 1, 2, 3, 4, 5, 6
  2. Filtro x > 3: sobram 4, 5, 6
  3. Multiplica por 3: 4*3, 5*3, 6*3
  => Resultado: [12, 15, 18]

• :t filter odd
  => Integral a => [a] -> [a]

• :t ("abc", True)
  => ([Char], Bool)  ou  (String, Bool)
8. SINTAXE RÁPIDA DE SOBREVIVÊNCIA
• Pattern Matching em Listas: (x:xs) onde x é a cabeça e xs é a cauda. [] é lista vazia.
• Guardas (|): func x | x == 0 = 1 | x > 0 = x * 2 | otherwise = -1
• Where (variáveis locais): delta = b*b - 4*a*c  (fica indentado no final da função)
• Tuplas: fst (1, 2) => 1  |  snd (1, 2) => 2  |  ("SP", 10, True) é uma 3-tupla fixa.
Regra de Ouro do Verso: No teste de mesa, mostre SEMPRE a tabela linha por linha para garantir a pontuação integral da questão!
