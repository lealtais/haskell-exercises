QUESTÃO 3 (3,0 pontos) — MODELAGEM DE DADOS COM 'DATA'
ENUNCIADO DA PROVA: Considere a modelagem de imóveis e bairros na linguagem Haskell. Implemente o que se pede:
(a) (2,0 pts) Defina o tipo de dado Imovel, contendo os value constructors Casa e Apartamento. Ambos devem armazenar: metragem quadrada e preço.
(b) (1,0 pt) Defina o tipo de dado Bairro, contendo os value constructors Pompeia e SantaMaria. Ambos devem armazenar: uma lista de imóveis do tipo [Imovel], uma descrição e o preço médio do metro quadrado. 
-- SOLUÇÃO (a): metragem quadrada (Float) e preço (Float)
data Imovel = Casa Float Float
            | Apartamento Float Float
            deriving (Show, Eq)

-- SOLUÇÃO (b): lista de imóveis [Imovel], descrição (String), preço médio m² (Float)
data Bairro = Pompeia [Imovel] String Float
            | SantaMaria [Imovel] String Float
            deriving (Show, Eq)

-- ALTERNATIVA VÁLIDA (Record Syntax):
data Imovel = Casa { metragem :: Float, preco :: Float } | Apartamento { metragem :: Float, preco :: Float } deriving (Show, Eq)
data Bairro = Pompeia { imoveis :: [Imovel], desc :: String, precoMedio :: Float } | SantaMaria { imoveis :: [Imovel], desc :: String, precoMedio :: Float } deriving (Show, Eq)
QUESTÃO 1 (1,0 ponto) — LISTA PRÓPRIA COM ':>:'
ENUNCIADO DA PROVA: Dado o tipo de dado algébrico List a = a :>: (List a) | Nulo, implemente a função removerElementoInicio que recebe um tipo List a e retorna um tipo List a sem o primeiro elemento. (remove o primeiro elemento do List a). 
data List a = a :>: (List a) | Nulo deriving (Show, Eq)

-- SOLUÇÃO OFICIAL:
removerElementoInicio :: List a -> List a
removerElementoInicio (x :>: xs) = xs
removerElementoInicio Nulo       = Nulo

-- 🚨 SE ELE PEDIR PARA REMOVER DO MEIO (por valor):
removerMeio :: (Eq a) => a -> List a -> List a
removerMeio _ Nulo = Nulo
removerMeio val (x :>: xs)
  | val == x  = xs                      -- achou: descarta x
  | otherwise = x :>: removerMeio val xs

-- 🚨 SE ELE PEDIR PARA REMOVER POR POSIÇÃO (índice 0, 1, 2...):
removerPos :: Int -> List a -> List a
removerPos _ Nulo = Nulo
removerPos 0 (_ :>: xs) = xs
removerPos n (x :>: xs) = x :>: removerPos (n-1) xs

ENUNCIADO DA PROVA: Dado o tipo de dado: data Arvore a = Galho a (Arvore a) (Arvore a) | Folha a | Nulo, e o desenho de árvore:
Raiz [Galho 30]; Esq: [Galho 20] (Esq: Nulo, Dir: Folha 3); Dir: [Galho 45] (Esq: Folha 41, Dir: Nulo).
Escreva a expressão em Haskell equivalente à árvore da imagem. 
data Arvore a = Galho a (Arvore a) (Arvore a)
              | Folha a | Nulo deriving (Show, Eq)

-- SOLUÇÃO OFICIAL (Expressão exata da questão):
arvoreResposta :: Arvore Int
arvoreResposta = 
  Galho 30 (Galho 20 Nulo (Folha 3))
           (Galho 45 (Folha 41) Nulo)

-- SE PEDIR FUNÇÃO NA ÁRVORE (Ex: Altura):
altura Nulo = 0
altura (Folha _) = 1
altura (Galho _ e d) = 1 + max (altura e) (altura d)

-- SE PEDIR SOMA DOS NÓS:
somaArv Nulo = 0
somaArv (Folha x) = x
somaArv (Galho x e d) = x + somaArv e + somaArv d
TEORIA RÁPIDA: DIFERENÇA ENTRE TYPE E DATA
• type (Apelido/Sinônimo): Não cria tipo novo, só dá nome alternativo.  Ex: type Nome = String  |  type Ponto = (Float, Float)
• data (Tipo Novo): Cria uma estrutura nova do zero. Construtores com MAIÚSCULA: data Dir = Norte | Sul | Leste | Oeste deriving Show

QUESTÃO 4 (2,0 pontos) — FUNÇÃO BAR E TESTE DE MESA
ENUNCIADO DA PROVA: Dado a implementação a seguir:
bar :: (Eq a) => (a -> Bool) -> [a] -> [a]
bar func [] = []
bar func (x:xs) | func x == True = x : bar func xs | otherwise = bar func xs
Responda: (a) O que essa função faz? (b) Faça um teste de mesa com o valor: bar (\x -> elem x "FEfe") "FATEC" 
-- SOLUÇÃO (a):
A função 'bar' filtra os elementos de uma lista com base em um predicado booleano ('func').
Se 'func x == True', o elemento 'x' é mantido; caso contrário, é descartado. É a reimplementação da função de alta ordem 'filter'.

QUESTÃO 5 (1,0 ponto) — AVALIAÇÃO DE EXPRESSÕES E TIPOS (:T)
ENUNCIADO DA PROVA: Analise as expressões em Haskell a seguir e responda ao que se pede. Para expressões com :t, informe o tipo retornado. Para as demais, apresente o resultado da avaliação.
(a) :t filter odd  |  (b) map (\x -> x * 2) [1,3,5,7]  |  (c) :t ("abc", True)  |  (d) foldl (+) 0 [2,4,6,8]  |  (e) [x * 3 | x <- [1..6], x > 3] 
-- SOLUÇÕES OFICIAIS:
(a) :t filter odd                    ==>  Integral a => [a] -> [a]
(b) map (\x -> x * 2) [1,3,5,7]      ==>  [2, 6, 10, 14]
(c) :t ("abc", True)                 ==>  ([Char], Bool)   (ou (String, Bool))
(d) foldl (+) 0 [2,4,6,8]            ==>  20                (cálculo: (((0 + 2) + 4) + 6) + 8 = 20)
(e) [x * 3 | x <- [1..6], x > 3]     ==>  [12, 15, 18]      (filtro x > 3 gera 4, 5, 6; vezes 3 = 12, 15, 18)
REVISÃO DE FOLDL vs FOLDR
• foldl (-) 10 [1, 2, 3]  (acumula da esquerda)
  => ((10 - 1) - 2) - 3 = 4
• foldr (-) 10 [1, 2, 3]  (acumula da direita)
  => 1 - (2 - (3 - 10)) = 1 - (2 - (-7)) = -8
• foldl (*) 1 [1, 2, 3, 4] => 1*1*2*3*4 = 24
RECURSÃO CLÁSSICA EM LISTAS (X:XS)
• Comprimento: tam [] = 0 ; tam (_:xs) = 1 + tam xs
• Somatória:   soma [] = 0 ; soma (x:xs) = x + soma xs
• Pertence:    elem' _ [] = False
               elem' e (x:xs) = e == x || elem' e xs
• Guardas:     sinal x | x > 0 = 1 | x < 0 = -1 | otherwise = 0
